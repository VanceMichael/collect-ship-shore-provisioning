# 资料提供方的格式

`/calls.json` 标出航次及停靠序位，对应的港、收货台、截止和离泊分钟。revision 只变更第一个停靠。`/supplier/cartons.csv` 既列有序号件，也列可拆通用品。lines 的 qty 是数量，allergen 为供应商使用说明标记，有不同标记不能替代。stop 为当前供给意向，ports 是本件允许登船的港。 `/supplier/repack.json` 为箱移出或分件记录，计量为件。
`/ship/demand.json` 是各航段需求和供给偏好，`/wharf/yard.json` 读码头暂存，`/ship/onboard.json` 读轮船实际登船确认。证据分别使用停靠序位、箱、实物和分钟，更新时间与提交时间可不同。
靠泊变更的发布时间见 revision_published_at。港间接驳表 routes 给起港及收货台、到港及收货台、可发车区间（左闭右开）和行车分钟。collection 给箱、当前港、交接台、提回观察时间和状态。waiting 表示还没交付提回，available 表示柜台可交。
